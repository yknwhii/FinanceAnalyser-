# UPDATES

## v0.2.0 — текущая

### Исправлено (баги)

* **«Чёрный экран» в start.bat** — `start.bat` использовал `where python`,
  которая в PATH находит stub Microsoft Store вместо реального Python.
  Теперь `start.bat` явно ищет Python в `%LOCALAPPDATA%\Programs\Python\PythonXY\python.exe`
  и только в самом конце использует `py -3`. Плюс добавлено `chcp 65001`
  для корректного отображения кириллицы.
* **`start.bat` падал с непонятной ошибкой кириллицы** — содержимое
  batch-файла было сохранено в UTF-8, а `cmd` его читал в OEM-кодировке,
  превращая кириллические строки в нераспознаваемые команды. Теперь
  в `start.bat` только ASCII-латиница; кириллица выводится уже
  самим `src/main.py`, который корректно работает в UTF-8.
* При ошибке конфигурации/данных `start.bat` теперь выводит
  «Press any key to exit...» и ждёт `pause`.
* `CURRENT_CAPITAL=0` корректно обрабатывается (формулы возвращают
  «недостаточный начальный капитал»); приложение запускается,
  не показывает «чёрный экран».
