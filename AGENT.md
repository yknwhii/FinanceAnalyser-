# Правила для агента

Этот файл — операционные правила для AI-агента, работающего с проектом `finance`.

## Общие принципы

- Никогда не удаляй комментарии, которые уже есть в коде. Можно менять на более актуальные, но не удалять, чтобы код оставался без них.
- Делай код атомарным: изменение в одном месте не должно ломать другие функции. Код должен легко поддерживаться, обновляться и масштабироваться.
- Важные новые функции, которые добавляешь, записывай в `UPDATES.md` с указанием текущей даты и версии приложения — это нужно для changelog'а обновлений платформы. После изменений делай коммит и перечисляй, что добавлено.
- Во время разработки интерфейса сразу адаптируй под мобильную версию (если применимо к типу интерфейса).
- В коде проекта не должно быть чувствительных данных (реальные пароли, логины, описания расходов и доходов). Вся конфиденциальная информация хранится ТОЛЬКО локально у пользователя.
- В сообщениях коммитов не упоминай модель нейросети и ссылки на сессию.
- Всегда отвечай пользователю на русском языке.

## Структура проекта

```
finance/
├── src/         # Исходный код (main.py, calc.py, draw.py, excel_parser.py)
├── charts/      # Графики и диаграммы
├── tests/       # Автоматические тесты
├── .env.example # Пример переменных окружения
├── .gitignore
├── start.bat    # Запуск приложения
├── package.json # Зависимости и команды проекта
├── AGENT.md     # Этот файл
├── doc.md       # Документация проекта
├── UPDATES.md   # Перечень изменений
└── README.md    # Основная документация
```

## Запуск и тесты

- Запуск: `start.bat` (или `python src/main.py`).
- Тесты: `python -m pytest tests --basetemp=./.pytest_tmp`.
- Перед коммитом прогоняй тесты, все должны быть зелёными.
