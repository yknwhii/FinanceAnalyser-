# finance

Локальное консольное приложение для анализа личных финансов: расходы,
портфель, время достижения финансовой цели и графики.

## Возможности

* автоматическая загрузка структуры расходов и портфеля из Excel при старте;
* расчёт месячных расходов и ожидаемой доходности портфеля;
* расчёт времени достижения финансовой цели по капиталу;
* расчёт необходимого дохода (капитал под пассивный доход / доход под цель);
* анализ зависимости срока от капитала, доходности и расходов;
* графики (показываются в отдельных окнах matplotlib — пользователь сам решает,
  сохранять ли изображение).

## Требования

* Windows 10/11;
* Python 3.10+;
* Зависимости из `package.json` (или `requirements.txt` для pip-стиля).

## Установка

Через pip:

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

## Настройка `.env`

Скопируйте `.env.example` в `.env` и укажите пути к Excel-файлам и
параметры (`INFLATION_PCT`, `CURRENT_CAPITAL`). Файл `.env` добавлен
в `.gitignore` — он остаётся только на вашем ПК.

## Запуск

Двойным кликом по `start.bat`. Если Python не найден, скрипт выведет
сообщение и предложит нажать любую клавишу для выхода.

Из консоли:

```bat
start.bat
```

или эквивалентно:

```bat
python src\main.py
```
